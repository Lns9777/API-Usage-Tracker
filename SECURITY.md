# Security Policy

## Supported Versions

The latest released version is the primary supported version.

## Reporting a Vulnerability

If you discover a security issue:

- Do not open a public issue
- Send a private report to the maintainers
- Include steps to reproduce, impact, and any suggested fix

## Scope

Security concerns include:

- Credential handling
- Sensitive data storage
- Remote code execution
- Data exposure in the backend, SDK, or frontend build pipeline
